# Cinemate

Cinemate is an iOS movie tracking application developed with SwiftUI.  
The project was iteratively developed throughout the semester as part of a self-directed professional learning plan focused on native iOS development, persistence management, API integration, testing workflows, and GitHub-based software engineering practices.

---

## Features

### Movie Discovery
- Browse currently playing movies
- Search movies using TMDB API
- View detailed movie information
- Async movie poster loading

### Personal Movie Records
- Save watched movie records
- Add ratings and comments
- Record companions and watch dates
- Favourite movie memories system

### Dashboard & Statistics
- Recently watched movies
- Favourite memories section
- Viewing statistics
- Most watched month
- Most frequent companion tracking

### Persistence
- CoreData integration
- Local record persistence
- Watchlist persistence

### Testing
- XCTest unit testing
- XCUITest UI automation testing
